# O20 Support Status

The current C++ SDK does not yet support O20. The public `Model` enum and `supported_models()` contain only
L6, O6, L20 Lite, L20, L30, and O30. There is no O20 model object, HandDevice configuration, or discovery integration.

This page keeps the original file path to document support status. The previously copied O20 Python examples do not apply to the C++ SDK;
you cannot pass Python model strings, interfaces, or joint counts directly to the C++ API, or use O20 as though it were O30.
