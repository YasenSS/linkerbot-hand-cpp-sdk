# O20 支持状态

当前 C++ SDK 尚未支持 O20。公开 `Model` 枚举和 `supported_models()` 中只有
L6、O6、L20 Lite、L20、L30、O30，没有 O20 的型号对象、HandDevice 配置或发现适配。

本页保留原文件路径作为支持状态说明。此前复制的 O20 Python 示例不适用于 C++ SDK，
不能将 Python 的型号字符串、接口或关节数直接传入 C++ API，也不能把 O20 当成 O30 使用。
