# L6 功能文档

L6 使用经典 CAN，包含 6 个关节。
本页以 C++ `HandDevice` 为常用操作入口，示例按当前 C++ SDK 接口编写。
默认指 Classic 固件；可选 HOP CAN FD 的能力和连接另见[协议说明](../guides/usage.md#l6-可选-can-fd-协议)。

## 使用方式

先按[准备接口](../connections/prepare-interface.md)配置环境，选择[自动连接](../connections/automatic.md)
或[手动连接](../connections/manual.md)。下面是 Linux SocketCAN 的完整只读程序，
提供本页后续片段使用的 `hand`、chrono 字面量和输出/等待函数。
Windows 连接时替换设备构造部分，传入已确认的 adapter factory；功能片段保持相同。

```cpp
#include <algorithm>
#include <chrono>
#include <cstdint>
#include <exception>
#include <iostream>
#include <stdexcept>
#include <string>
#include <vector>
#include <linkerbot/hand/api/device.hpp>

using namespace linkerbot::hand;
using namespace std::chrono_literals;

template<class Values>
void print_values(const Values &values) {
    for (const auto value : values) {
        std::cout << +value << ' ';
    }
    std::cout << '\n';
}

void check_sample(const SampleMeta &meta) {
    if (!meta.valid) {
        throw std::runtime_error("样本不可用");
    }
    if (meta.stale) {
        std::cerr << "样本已超过新鲜度窗口，请按业务要求重新读取\n";
    }
}

void wait_command(const CommandHandle &command) {
    if (!command.wait_for(2s)) {
        throw std::runtime_error("等待超时；命令未取消，不自动重发");
    }
    if (const auto error = command.error()) {
        std::rethrow_exception(error);
    }
    const auto stage = command.stage();
    if (stage != CommandStage::kAcknowledged &&
        !(stage == CommandStage::kDispatched && command.ack_expectation() == AckExpectation::kNone)) {
        throw std::runtime_error("命令未成功完成，可能已被替换或取消");
    }
}

void print_sample(const RawVectorSample &sample) {
    check_sample(sample.meta);
    print_values(sample.raw);
}

void print_field(const ForceSample &force, const std::string &name) {
    const auto *field = force.field(name);
    if (!field) {
        std::cout << name << ": " << force.status(name) << '\n';
        return;
    }
    check_sample(field->meta);
    for (size_t finger = 0; finger < field->raw.size(); ++finger) {
        if (!field->raw[finger]) {
            std::cout << "finger " << finger << ": 无数据\n";
            continue;
        }
        const auto &values = *field->raw[finger];
        for (size_t point = 0; point < values.size(); ++point) {
            if (finger < field->valid_values.size() && field->valid_values[finger] &&
                point < field->valid_values[finger]->size() && !(*field->valid_values[finger])[point]) {
                std::cout << "invalid ";
            } else {
                std::cout << values[point] << ' ';
            }
        }
        std::cout << '\n';
    }
}

int main() try {
    HandDeviceConfig config;
    config.model = Model::kL6;
    config.side = HandSide::kLeft; // 改为实际侧别
    config.interface_name = "can0"; // 此完整程序使用 Linux SocketCAN
    HandDevice hand(config);
    std::exception_ptr failure;
    try {
        hand.open();
        // 将下文所需的功能片段放在这里；不要一次执行整篇所有控制示例。
        const auto angles = hand.get_angles(1s);
        check_sample(angles.meta);
        print_values(angles.raw);
    } catch (...) {
        failure = std::current_exception();
    }
    try {
        hand.close();
    } catch (const std::exception &error) {
        if (!failure) {
            throw;
        }
        std::cerr << "关闭连接失败：" << error.what() << '\n';
    }
    if (failure) {
        std::rethrow_exception(failure);
    }
    return 0;
} catch (const std::exception &error) {
    std::cerr << error.what() << '\n';
    return 1;
}
```

下文普通 C++ 片段分别放到 `hand.open()` 成功之后、`hand.close()` 之前，
并保留这些辅助函数；它们不是独立程序，也不应一次执行全部控制操作。
专用 Manager 小节另外提供独立程序。

统一 setter 和 `enable()` / `disable()` 等离散操作返回 `CommandHandle`。
`wait_command()` 先等待终结，再检查错误和终态：`kAcknowledged` 或无 ACK 的 `kDispatched`
才按对应协议视为通信完成。被替换、取消或失败都不是成功；等待超时不取消命令，不自动重发。
机械到位和控制效果需要业务另外验证。

样本先检查 `meta.valid`，并按 `meta.stale` 判断是否过期；缓存读数不是实时测量。
关闭异常时长期应用应保留同一对象安排清理重试，不能直接另开连接。

## 关节顺序

SDK 按以下顺序读取和设置关节数据。

| 索引编号 | 关节名称 | 关节 |
| ---: | --- | --- |
| 1 | `thumb_flex` | 拇指弯曲 |
| 2 | `thumb_abd` | 拇指侧摆 |
| 3 | `index` | 食指 |
| 4 | `middle` | 中指 |
| 5 | `ring` | 无名指 |
| 6 | `pinky` | 小指 |

表格序号从 1 开始；C++ 向量下标为 `0..5`，以能力表 `joints[index].name` 为准。

<a id="identity"></a>

## 身份识别

`get_device_info(1s)` 主动读取并核验身份；C++ 返回结构体，按字段查看而不是直接打印整个对象。
`get_identity()` 只读取当前连接代的身份缓存。

```cpp
const auto info = hand.get_device_info(1s);
std::cout << "序列号：" << info.serial_number.value_or("设备未报告") << '\n';
std::cout << "产品：" << info.product_code.value_or("设备未报告") << '\n';
```

<a id="capabilities"></a>

## 能力查询

`get_capabilities()` 不发送控制命令。用能力表确认当前型号/协议是否支持操作，
尤其是同一型号的不同固件、协议和传感器。关节下标从 0 开始；下表序号从 1 开始。

```cpp
const auto caps = hand.get_capabilities();
std::cout << caps.serialize() << '\n';
for (const auto &joint : caps.joints) {
    std::cout << joint.index << ": " << joint.name << " raw="
              << joint.raw_angle_range.minimum << ".." << joint.raw_angle_range.maximum << '\n';
}
```

<a id="angle-control"></a>

## 角度控制

原始角度为 `0..255`，默认百分比与原始值同向。具体机械姿态按关节、侧别及实际角度映射判断，
不能把侧摆或旋转轴的两个端点简单等同于“弯曲/伸直”。

### 角度读取

`AngleSample::raw` 是 `vector<double>`；`percent` 是逐关节的 `optional<double>`，
无法换算的百分比不能补成 0。

```cpp
const auto sample = hand.get_angles(1s);
check_sample(sample.meta);
print_values(sample.raw);
for (const auto &percent : sample.percent) {
    if (percent) {
        std::cout << *percent << ' ';
    } else {
        std::cout << "unavailable ";
    }
}
std::cout << '\n';
```

### 原始角度设置

`set_angles()` 接收 6 个 `int32_t`，按关节表顺序排列。下面读取当前值作为示例目标，
实际业务中替换为已确认且在范围内的目标；仍会发送控制帧，不保证设备不会运动。

```cpp
const auto modes = hand.get_torques(1s);
check_sample(modes.meta);
if (std::any_of(modes.raw.begin(), modes.raw.end(), [](double value) { return value != 0; })) {
    throw std::runtime_error("存在力矩模式关节；先通过 L6 专用 Manager 切回位置模式");
}
const auto sample = hand.get_angles(1s);
check_sample(sample.meta);
std::vector<int32_t> targets(sample.raw.begin(), sample.raw.end());
wait_command(hand.set_angles(targets));
const auto after = hand.get_angles(1s);
check_sample(after.meta);
print_values(after.raw);
```

### 百分比角度设置

`set_percent_angles()` 接收 6 个 `float`，范围 `0..100`。`50.0F` 仅表示各轴映射中点，
不是经过验证的通用安全姿态；应按实际任务替换。

```cpp
const auto modes = hand.get_torques(1s);
check_sample(modes.meta);
if (std::any_of(modes.raw.begin(), modes.raw.end(), [](double value) { return value != 0; })) {
    throw std::runtime_error("存在力矩模式关节；先通过 L6 专用 Manager 切回位置模式");
}
std::vector<float> targets(6, 50.0F);
wait_command(hand.set_percent_angles(targets));
```

<a id="speed-control"></a>

## 速度控制

### 速度设置

原始设置范围为 `0..255`，不是已确认的物理转速。

```cpp
wait_command(hand.set_speeds(std::vector<double>(6, 100.0)));
```

### 速度配置读取

配置速度读取的是本次连接中完整速度写回复的缓存，不发送新的速度查询。
先执行速度设置，再在同一连接中读取；`get_speeds()` 实时速度接口不支持。

```cpp
print_sample(hand.get_configured_speeds(1s));
```

<a id="torque-control"></a>

## 力矩控制

Classic L6 的力矩写入通过专用 `l6::L6::torque` Manager，不调用统一层的 `set_torques()`。
读取到的 `0` 表示位置模式，`1..255` 表示力矩模式及输出等级，不是 N·m 实测力矩。

### 专用对象连接

这是独立完整程序。先关闭前面创建的 `HandDevice` 再使用它；不能同时打开两个对象竞争同一台设备。
型号对象构造时建立资源，结束使用 `stop()`，不调用 `open()` 或 `close()`。

```cpp
#include <array>
#include <chrono>
#include <cstdint>
#include <exception>
#include <iostream>
#include <linkerbot/hand/l6/l6.hpp>

using namespace std::chrono_literals;

int main() try {
    namespace l6 = linkerbot::hand::l6;
    l6::L6 native_hand(l6::Side::kLeft, "can0");
    std::exception_ptr failure;
    try {
        const auto identity = native_hand.version.get_verified_device_info(2s);
        (void)identity;
        // 这里只读取当前力矩模式值；下面各小节的 Manager 片段可替换此处。
        const auto data = native_hand.torque.get_blocking(1s);
        for (const auto value : data.torque.to_array()) {
            std::cout << static_cast<unsigned>(value) << ' ';
        }
        std::cout << '\n';
    } catch (...) {
        failure = std::current_exception();
    }
    try {
        native_hand.stop();
    } catch (const std::exception &error) {
        if (!failure) {
            throw;
        }
        std::cerr << "停止连接失败：" << error.what() << '\n';
    }
    if (failure) {
        std::rethrow_exception(failure);
    }
    return 0;
} catch (const std::exception &error) {
    std::cerr << error.what() << '\n';
    return 1;
}
```

### 位置模式设置

以下片段放入原生程序的 `try` 内，使用其中的 `native_hand`。写入 0 切回位置模式，
不会自动发送新的角度目标。`set_torques()` 返回 `void`，没有 `CommandHandle`，
发送后可查询当前模式值，不能对返回值调用 `wait_for()`。

```cpp
std::array<uint8_t, 6> modes{};
// 所有关节写 0，切回位置模式。
native_hand.torque.set_torques(modes);
const auto actual = native_hand.torque.get_blocking(1s);
for (const auto value : actual.torque.to_array()) {
    std::cout << static_cast<unsigned>(value) << ' ';
}
```

### 力矩输出设置

以下会切入力矩模式，输出等级仅是协议计数，必须按任务调整。

```cpp
std::array<uint8_t, 6> levels{};
levels.fill(10);
native_hand.torque.set_torques(levels);
```

### 力矩协议值读取

统一对象可用 `hand.get_torques(1s)` 读取；原生对象使用 `native_hand.torque.get_blocking(1s)`。
两种对象分别使用，不为一次读取额外建立第二条连接。

<a id="native-gains"></a>

## 位置 Kp、位置 Kd 与扭矩 Kd

这三项能力在本教程中只通过 L6 专用 Manager 使用：
`position_kp`、`position_kd`、`torque_kd`。以下片段替换原生程序 `try` 内的读取代码。
位置 Kp 原始范围 `0..200`，另外两项为 `0..255`；不把推荐值当硬限制，
也不在物理比例尚有冲突时宣称统一的工程单位。

```cpp
const auto kp = native_hand.position_kp.get_blocking(1s);
const auto kd = native_hand.position_kd.get_blocking(1s);
const auto torque_kd = native_hand.torque_kd.get_blocking(1s);
for (const auto value : kp.values) {
    std::cout << static_cast<unsigned>(value) << ' ';
}
std::cout << '\n';
// 示例原样写回已读取的值，实际调整前确认设备控制模式及增益目标。
native_hand.position_kp.set_values(kp.values, 1s);
native_hand.position_kd.set_values(kd.values, 1s);
native_hand.torque_kd.set_values(torque_kd.values, 1s);
```

`set_values()` 同步等待写回复，返回 `void`。固件可能回复写入前的旧值，
收到回复不能证明新参数已生效；需要确认时另行主动查询并核对实际响应。

<a id="sensor-reading"></a>

## 传感器数据读取

### 电流读取

`get_currents()` 读取实际电流原始计数，和电流上限设置不同；没有可靠比例时不标成 mA。

```cpp
print_sample(hand.get_currents(1s));
```

### 温度读取

本型号温度能力表声明单位为摄氏度；仍须检查样本有效性。

```cpp
print_sample(hand.get_temperatures(1s));
```

### 触觉点阵读取

C++ 使用 `get_force(vector<string>{"fn"}, timeout)` 选择字段，并通过 `field("fn")` 读取，
不是 Python 的 `force.fn.raw`。`raw` 中每个可选向量对应一个手指；`nullopt` 表示缺失，
`valid_values` 中的 `false` 表示该值无效。前置函数 `print_field()` 按这些信息显示，不补零、不自行求和。

```cpp
const auto force = hand.get_force(std::vector<std::string>{"fn"}, 1s);
print_field(force, "fn");
```

默认点阵形状为 5 个手指，每指 12×6。返回字段及 `force.tactile` 保留实际数据；以当前能力和固件为准。

更多功能、固件限制和物理单位说明见[各型号能力说明](../reference/model-capabilities.md)。
